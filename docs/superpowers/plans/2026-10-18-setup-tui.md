# Setup TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the interactive prompting layer of the four installer scripts (`setup.sh`, `setup.ps1`, `setup-mcp.sh`, `setup-mcp.ps1`) with a shared, dependency-free arrow-key/checkbox TUI, leaving everything those scripts install unchanged.

**Architecture:** Two new shared libraries — `lib/tui.sh` (sourced) and `lib/tui.ps1` (dot-sourced) — expose the same primitives in both languages: a banner, single-select menu, checkbox multi-select, text input, and confirm. Each installer sources its library and calls the primitives where it currently prints a numbered list and reads a line. A zero-dependency test harness (`tests/run.sh`, `tests/run.ps1`) drives the libraries through a pseudo-terminal and pins the installers' non-interactive output.

**Tech Stack:** bash 3.2+, PowerShell 5.1 and 7, `script(1)` for pty-driven tests.

**Spec:** `docs/superpowers/specs/2026-10-18-setup-tui-design.md`

## Global Constraints

- **bash 3.2+.** No `${var,,}`, associative arrays, `mapfile`, or `read -t` with a fractional timeout. An `Esc` keypress must never block waiting for a sequence tail.
- **PowerShell 5.1+ and 7.** No ternary, `??`, `::new()`, or `$IsWindows`.
- **No literal non-ASCII bytes in any `.ps1` file.** Build glyphs from `[char]` code points at runtime. `.sh` files may carry UTF-8 literals.
- **ASCII fallback is automatic**, never a flag: non-UTF-8 locale or `TERM=dumb` in bash; an unrenderable console in PowerShell.
- **Drawing to the terminal, values to the caller.** bash helpers draw to stderr and print the value to stdout (preserving `choice="$(...)"`); PowerShell helpers draw with `Write-Host` and `return`.
- **Comments match existing density.** Explain non-obvious intent only; never restate code.
- **No change to install/clean/merge logic, file formats, markers, backups, or exit codes** except: a clean "No" exits 0, `Ctrl-C` exits 130.
- **Non-interactive runs stay silent** — no prompts and no ANSI bytes when stdin/stdout is not a terminal.
- `MCP_ASSUME_TTY=1` keeps meaning "pretend a terminal exists".

## Review Focus

Each line is a failure mode the spec implies; the named task adds its test.

1. A non-tty run emits ANSI escape bytes into redirected output. (Task 3 and Task 5.)
2. A lone `Esc` hangs the reader on bash 3.2. (Task 1.)
3. Every checkbox in a multi-select left unchecked silently proceeds, installing everything or nothing. (Task 1 and Task 5.)
4. `Ctrl-C` leaves the terminal in raw mode with a hidden cursor. (Task 1 and Task 2.)
5. Glyphs render as mojibake under PowerShell 5.1 because the `.ps1` carries literal UTF-8. (Task 2.)

### Task 1: bash TUI library and test harness

**Files:**
- Create: `lib/tui.sh`
- Create: `tests/run.sh`

**Interfaces:**
- Produces (all in `lib/tui.sh`): `tui_init`, `tui_cleanup`, `tui_banner TITLE`, `tui_menu TITLE DEFAULT OPTION...` (prints 0-based index to stdout), `tui_multi TITLE DEFAULTS OPTION...` (prints a `0`/`1` string, one char per option, to stdout), `tui_input TITLE DEFAULT` (prints the string), `tui_confirm QUESTION` (exit status 0=yes, 1=no). Sets `TUI_ANSI`, `TUI_UNICODE`, colour vars (`TUI_BOLD`, `TUI_DIM`, `TUI_CYAN`, `TUI_GREEN`, `TUI_GREY`, `TUI_YELLOW`, `TUI_RESET`) and glyph vars (`TUI_POINTER`, `TUI_RADIO_ON`, `TUI_RADIO_OFF`, `TUI_RULE`, `TUI_DOT`). `tui_multi` refuses to advance when every option is off.
- Consumes: nothing.

- [ ] **Step 1: Create the test harness `tests/run.sh`**

A zero-dependency runner: defines `assert_eq <label> <want> <got>`, `assert_contains <label> <haystack> <needle>`, `assert_no_ansi <label> <text>` (fails on `ESC[`); discovers and runs every `test_*` function; prints `ok`/`FAIL` per test; exits 1 if any failed. Add `pty_drive <driver-path> <keystrokes>` which runs `printf '%b' "$keystrokes" | script -qec "bash <driver-path>" /dev/null`; if `script` is not on PATH, print `SKIP: pty tests (script(1) not found)` and return 2. Add a `mk_driver <body>` helper writing an executable temp script under a temp dir.

- [ ] **Step 2: Write the failing tests**

In `tests/run.sh` add:
- `test_glyph_ascii_fallback` — `TERM=dumb LANG=C src lib/tui.sh; tui_init; printf '%s' "$TUI_POINTER"` contains no non-ASCII byte.
- `test_menu_down_enter_selects_second` — driver sources the lib, `idx=$(tui_menu "Pick" 0 Alpha Beta)`, prints `RESULT=$idx`; keys `\x1b[B\n`; assert output contains `RESULT=1`.
- `test_menu_digit_jumps` — keys `3\n`; assert `RESULT=2`.
- `test_multi_space_toggles` — driver `v=$(tui_multi "Pick" 11 A B); echo "RESULT=$v"`; keys `\n\n` (move down is not needed: toggle first option off, confirm); assert `RESULT=01`.
- `test_multi_requires_one` — driver with defaults `00`; keys `\n\n`; assert `RESULT=11` is absent and the run does not hang (pty_drive returns before the harness timeout).
- `test_input_types_and_backspaces` — driver `s=$(tui_input "Path" /base); echo "RESULT=$s"`; keys `x\x7f\x7f\n`; assert `RESULT=/ba`.
- `test_confirm_no_is_status_1` — driver `if tui_confirm "Go?"; then echo "RESULT=yes"; else echo "RESULT=no"; fi`; keys `n`; assert `RESULT=no`.
- `test_lone_esc_does_not_hang` — driver `tui_menu "Pick" 0 A B` with `tui_init`; keys `\x1b`; assert the pty run returns (no timeout) — pin by running `pty_drive` under `timeout 10`.

- [ ] **Step 3: Run the tests to verify they fail**

Run: `bash tests/run.sh`
Expected: FAIL — `lib/tui.sh` missing / functions not defined.

- [ ] **Step 4: Implement `lib/tui.sh`**

`tui_init`: save `stty -g`, set `stty -echo -icanon min 1 time 0`, hide the cursor via ANSI when available; install an `EXIT`/`INT`/`TERM` trap calling `tui_cleanup`. Set `TUI_UNICODE=0` when `TERM=dumb` or the locale is not UTF-8, else `1`, and assign the glyph vars from that. `tui_cleanup`: restore `stty`, show cursor, idempotent. `_tui_read_key`: read one byte with `read -rsn1`; on `ESC`, read up to two more bytes **without a fractional timeout** (spec's bash-3.2 constraint) so a lone `Esc` cannot block; map to tokens `up down left right enter space backspace esc` or the literal char. `_tui_wipe`/`_tui_draw`: redraw the dynamic block to stderr, tracking the line count. `tui_menu`, `tui_multi`, `tui_input`, `tui_confirm`, `tui_banner`: per the Interfaces block; all drawing via `>&2`, all values via stdout (except `tui_confirm`'s status).

- [ ] **Step 5: Run the tests to verify they pass**

Run: `bash tests/run.sh`
Expected: PASS for every test; pty tests skip cleanly when `script` is absent.
